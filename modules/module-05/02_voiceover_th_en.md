- **EN Reference:**  
  Detection counts scrap after money is wasted; SPC provides prevention by signaling process drift while parts are still inside specification.

## LESSON M5-L2: Control Chart Principle

### AUD-M5L2-S01 (35 sec) — Anatomy of a Control Chart
- **Display Script (TH):**  
  บน Control Chart จะมีเส้น 3 เส้นและแถบโซนครับ [PAUSE-1] [ANIM: chart_zones] เส้นกลางคือ **Center Line (`CL`)** ส่วนเส้นบนกับเส้นล่างคือ **`UCL` และ `LCL`** ซึ่งตั้งอยู่ที่ระยะ **`±3 ซิกม่า`** จากค่ากลาง [PAUSE-1] ถ้าจินตนาการเอา Bell Curve มาตั้งตะแคง เราจะแบ่งพื้นที่ออกเป็น **Zone C (`±1σ`), Zone B (`1–2σ`) และ Zone A (`2–3σ`)** ไว้ใช้อ่านสัญญาณเตือนล่วงหน้าครับ
- **TTS Clean Script (TH):**  
  บน คอนโทรล ชาร์ท จะมีเส้น 3 เส้นและแถบโซนครับ, เส้นกลางคือ เซ็นเตอร์ ไลน์ ส่วนเส้นบนกับเส้นล่างคือ ยูซีแอล และ แอลซีแอล ซึ่งตั้งอยู่ที่ระยะ บวกลบ 3 ซิกม่า จากค่ากลาง, ถ้าจินตนาการเอา เบลล์ เคิร์ฟ มาตั้งตะแคง เราจะแบ่งพื้นที่ออกเป็น โซน ซี โซน บี และ โซน เอ ไว้ใช้อ่านสัญญาณเตือนล่วงหน้าครับ
- **EN Reference:**  
  A control chart plots the Center Line with UCL and LCL at plus-or-minus three sigma, divided into Zones C, B, and A for sensitive pattern detection.

### AUD-M5L2-S02 (45 sec) — Control Limits vs Spec Limits
- **Display Script (TH):**  
  ข้อผิดพลาดอันดับหนึ่งของโรงงานคือ **เอาเส้น Spec (`USL/LSL`) มาวาดเป็น Control Limit บนกราฟ $\bar{X}$!** [PAUSE-1] [ANIM: spec_vs_control] จำให้ขึ้นใจนะครับ: **`USL/LSL`** เป็นเสียงลูกค้าใช้ตรวจ **ชิ้นงานรายชิ้น** ส่วน **`UCL/LCL`** เป็นเสียงเครื่องจักรใช้ตรวจ **ค่าเฉลี่ยของ Subgroup** ซึ่งแคบกว่าชิ้นเดี่ยวถึง **$\sqrt{n}$ เท่า!** [PAUSE-1] ถ้าเอาเส้น Spec มาวางแทน กว่ากราฟจะเตือน ของเสียก็ล้นสายพานไปแล้วครับ
- **TTS Clean Script (TH):**  
  ข้อผิดพลาดอันดับหนึ่งของโรงงานคือ เอาเส้น สเปก มาวาดเป็น คอนโทรล ลิมิต บนกราฟ เอ็กซ์บาร์, จำให้ขึ้นใจนะครับ ยูเอสแอล แอลเอสแอล เป็นเสียงลูกค้าใช้ตรวจ ชิ้นงานรายชิ้น ส่วน ยูซีแอล แอลซีแอล เป็นเสียงเครื่องจักรใช้ตรวจ ค่าเฉลี่ยของ ซับกรุ๊ป ซึ่งแคบกว่าชิ้นเดี่ยวถึง รูท เอ็น เท่า, ถ้าเอาเส้น สเปก มาวางแทน กว่ากราฟจะเตือน ของเสียก็ล้นสายพานไปแล้วครับ
- **EN Reference:**  
  Never plot specification limits on an X-bar control chart. Spec limits judge individual parts, while control limits monitor subgroup means that are narrower by square root of n.

### AUD-M5L2-S03 (40 sec) — Calculating UCL/CL/LCL
- **Display Script (TH):**  
  สูตรคำนวณเส้นควบคุมของ $\bar{X}$-$R$ Chart ไม่ต้องนั่งถอดรูทให้เหนื่อยครับ [ANIM: limit_constants] เราใช้ค่าคงที่มาตรฐานจาก AIAG อย่างที่ **`n = 5`** ใช้ **`A2 = 0.577` และ `D4 = 2.114`** เอาค่าเฉลี่ยพิสัย $\bar{R}$ มาคูณตรงๆ ได้ทั้ง `UCL_X`, `LCL_X` และ `UCL_R` อย่างรวดเร็วครับ
- **TTS Clean Script (TH):**  
  สูตรคำนวณเส้นควบคุมของ เอ็กซ์บาร์ อาร์ ชาร์ท ไม่ต้องนั่งถอดรูทให้เหนื่อยครับ เราใช้ค่าคงที่มาตรฐานจาก เอไอเอจี อย่างที่ เอ็น เท่ากับ 5 ใช้ เอทู เท่ากับ 0.577 และ ดีโฟร์ เท่ากับ 2.114 เอาค่าเฉลี่ยพิสัย อาร์บาร์ มาคูณตรงๆ ได้ทั้ง ยูซีแอล เอ็กซ์ แอลซีแอล เอ็กซ์ และ ยูซีแอล อาร์ อย่างรวดเร็วครับ
- **EN Reference:**  
  X-bar and R control limits use standard AIAG constants such as A2 equals 0.577 and D4 equals 2.114 for subgroups of five.

### AUD-M5L2-S04 (40 sec) — Phase I vs Phase II
- **Display Script (TH):**

- **EN Reference:**  
  Phase 1 establishes trial limits over 20–25 subgroups and removes only assignable-cause points. Phase 2 freezes those limits for ongoing monitoring so drift cannot widen the boundaries.

## LESSON M5-L3: Stability Assessment

### AUD-M5L3-S01 (35 sec) — Stability & Reading Order
- **Display Script (TH):**  
  เมื่อเปิดกราฟ $\bar{X}$-$R$ ขึ้นมา กฎข้อแรกคือ **ต้องดู $R$ Chart ข้างล่างก่อนดู $\bar{X}$ Chart ข้างบนเสมอครับ!** [PAUSE-1] [ANIM: read_r_first] เพราะความกว้างเส้นของ $\bar{X}$ คำนวณมาจาก $\bar{R}$ ถ้า $R$ Chart ยังแกว่งหลุดควบคุม เส้นบนกราฟ $\bar{X}$ ก็จะใช้ตัดสินไม่ได้ ต้องแก้ความนิ่งภายในกลุ่มก่อนครับ
- **TTS Clean Script (TH):**  
  เมื่อเปิดกราฟ เอ็กซ์บาร์ อาร์ ขึ้นมา กฎข้อแรกคือ ต้องดู อาร์ ชาร์ท ข้างล่างก่อนดู เอ็กซ์บาร์ ชาร์ท ข้างบนเสมอครับ, เพราะความกว้างเส้นของ เอ็กซ์บาร์ คำนวณมาจาก อาร์บาร์ ถ้า อาร์ ชาร์ท ยังแกว่งหลุดควบคุม เส้นบนกราฟ เอ็กซ์บาร์ ก็จะใช้ตัดสินไม่ได้ ต้องแก้ความนิ่งภายในกลุ่มก่อนครับ
- **EN Reference:**  
  Always evaluate the Range chart before the X-bar chart, because X-bar control limits depend directly on R-bar.

### AUD-M5L3-S02 (40 sec) — Sudden Shift & Trend Signatures
- **Display Script (TH):**  
  รูปทรงของจุดบนกราฟบอกใบ้ต้นตอในโรงงานได้แม่นยำมากครับ [ANIM: shift_trend] ถ้ากราฟ **กระโดดข้ามระดับทันที (Sudden Shift)** มักเกิดจากเปลี่ยนล็อตวัตถุดิบหรือตั้ง Offset ใหม่ [PAUSE-1] แต่ถ้า **ค่อยๆ เอียงขึ้นหรือลงเป็นทางลาด (Trend)** มักเป็นการสึกหรอของมีดกลึง หรืออุณหภูมิเครื่องจักรที่สะสมเพิ่มขึ้นครับ
- **TTS Clean Script (TH):**  
  รูปทรงของจุดบนกราฟบอกใบ้ต้นตอในโรงงานได้แม่นยำมากครับ ถ้ากราฟ กระโดดข้ามระดับทันที มักเกิดจากเปลี่ยนล็อตวัตถุดิบหรือตั้ง ออฟเซ็ต ใหม่, แต่ถ้า ค่อยๆ เอียงขึ้นหรือลงเป็นทางลาด มักเป็นการสึกหรอของมีดกลึง หรืออุณหภูมิเครื่องจักรที่สะสมเพิ่มขึ้นครับ
- **EN Reference:**  
  Sudden shifts point to lot changes, setups, or offsets, while steady trends indicate gradual tool wear or thermal buildup.

- **Display Script (TH):**

### AUD-M5L4-S04 (55 sec) — Smart SPC Rule Selection: Mandatory Rules, Zero-Bounds & Engineering Judgement
- **Display Script (TH):**  
  ทีนี้มาดูวิธีเลือกตั้งค่า SPC Rules อย่างมืออาชีพครับ [PAUSE-1] [ANIM: rule_selection_bounds] ปกติ **Rule 1 (`1 จุดนอก UCL/LCL`)** บน Mean Chart ใช้ได้ทั้งขอบบนและขอบล่าง แต่ระวังลักษณะงานแบบ **ยิ่งน้อยยิ่งดี** เช่น **Roughness, Flatness, Coplanarity หรือ Tilt** ที่ค่ามักเข้าใกล้ศูนย์ ทำให้สูตรคำนวณ **`LCL` ติดลบ** ซึ่งในโลกจริงวัดค่าติดลบไม่ได้ `LCL` นั้นจึงไม่ Valid ต้องตัดฝั่ง `LCL` ทิ้งและเช็กเฉพาะ **`UCL`** ครับ [PAUSE-1] เช่นเดียวกับ **Variation Chart (`R` หรือ `S`)** ที่มีค่าต่ำสุดคือศูนย์ เมื่อ `LCL = 0` ก็ไม่จำเป็นต้องตั้งกฎเช็กต่ำกว่า `LCL` ครับ [PAUSE-1] นอกจากนี้ในระบบยุคใหม่ เรายังเพิ่มกฎตรวจ **Individual Raw Data เทียบกับ Specification Limits** ควบคู่กับ **Rule 1** เรียกกลุ่มนี้ว่า **Mandatory SPC Rules** ที่ทุกชาร์ตต้องมี [PAUSE-1] ส่วนกฎเสริมที่เหลือ **ควรเลือกเปิดอย่างน้อย 1 ข้อ** โดยอาศัยทั้ง **Engineering Judgement** และ **Process Characteristic** วิศวกรต้องเข้าใจกระบวนการของตัวเองจริงๆ เพื่อหลีกเลี่ยง False Alarm ครับ
- **TTS Clean Script (TH):**  
  ทีนี้มาดูวิธีเลือกตั้งค่า เอสพีซี รูลส์ อย่างมืออาชีพครับ, ปกติ รูล 1 หรือ 1 จุดนอก ยูซีแอล แอลซีแอล บน มีน ชาร์ท ใช้ได้ทั้งขอบบนและขอบล่าง แต่ระวังลักษณะงานแบบ ยิ่งน้อยยิ่งดี เช่น รัฟเนส แฟลตเนส โคพลานาริตี้ หรือ ทิลต์ ที่ค่ามักเข้าใกล้ศูนย์ ทำให้สูตรคำนวณ แอลซีแอล ติดลบ ซึ่งในโลกจริงวัดค่าติดลบไม่ได้ แอลซีแอล นั้นจึงไม่แวลิด ต้องตัดฝั่ง แอลซีแอล ทิ้งและเช็กเฉพาะ ยูซีแอล ครับ, เช่นเดียวกับ แวริเอชั่น ชาร์ท อย่าง อาร์ หรือ เอส ที่มีค่าต่ำสุดคือศูนย์ เมื่อ แอลซีแอล เท่ากับศูนย์ ก็ไม่จำเป็นต้องตั้งกฎเช็กต่ำกว่า แอลซีแอล ครับ, นอกจากนี้ในระบบยุคใหม่ เรายังเพิ่มกฎตรวจ อินดิวิจวล รอว์ ดาต้า เทียบกับ สเปซิฟิเคชั่น ลิมิต ควบคู่กับ รูล 1 เรียกกลุ่มนี้ว่า แมนดาโทรี เอสพีซี รูลส์ ที่ทุกชาร์ตต้องมี, ส่วนกฎเสริมที่เหลือ ควรเลือกเปิดอย่างน้อย 1 ข้อ โดยอาศัยทั้ง เอนจิเนียริง จัดจ์เมนต์ และ โพรเซส คาแร็กเทอริสติก วิศวกรต้องเข้าใจกระบวนการของตัวเองจริงๆ เพื่อหลีกเลี่ยง ฟอลส์ อะลาร์ม ครับ
- **EN Reference:**  
  Rule 1 checks both UCL and LCL on standard mean charts. However, for lower-is-better traits near zero—like roughness, flatness, coplanarity, or tilt—a negative calculated LCL is physically impossible and invalid, so monitor only UCL. Likewise, on variation charts where the physical minimum is zero, an LCL of zero needs no lower rule check. Together with modern individual raw data versus specification checks, these form Mandatory SPC Rules required on every chart. Remaining rules should have at least one option selected using engineering judgement and process characteristics to prevent false alarms.
