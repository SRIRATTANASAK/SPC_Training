# Module 5 Workshop Guide & Verified Solutions

คู่มือปฏิบัติการ Workshop ประจำ Module 5 พร้อมเฉลยคำนวณทุกขั้นตอนที่ตรวจสอบความถูกต้อง 100% จากข้อมูลจริง

---

## Workshop: หา Special Cause จาก Control Chart ข้อมูลจริง (`M5L4-S07` & `S08`)
- **ไฟล์ข้อมูล:** [data/workshop_m5_control_chart_subgroups.csv](data/workshop_m5_control_chart_subgroups.csv)
- **บริบทหน้างาน:** วัดเส้นผ่านศูนย์กลางเพลาจากเครื่องกลึง CNC (`Shaft_OD_mm`) จำนวน **`125` ชิ้น** (`25 Subgroups × 5 ชิ้นต่อเนื่องทุกชั่วโมง`)
- **สเปกลูกค้า (VOC):** `25.000 ± 0.080 mm` → **`LSL = 24.920 mm`**, **`USL = 25.080 mm`**
- **ค่าคงที่สำหรับ `n = 5` (AIAG SPC):** `A2 = 0.577`, `D3 = 0.000`, `D4 = 2.114`, `d2 = 2.326`

### เฉลย Step 1: คำนวณ Trial Control Limits (`All 25 Subgroups`)

| ค่าที่คำนวณ | สูตร | ผลลัพธ์จริงจาก CSV |
|---|---|---|
| **Grand Mean ($\text{CL}_{\bar{X}} = \bar{\bar{x}}$)** | $\sum \bar{X}_i / 25$ | **`25.0067 mm`** |
| **Average Range ($\text{CL}_R = \bar{R}$)** | $\sum R_i / 25$ | **`0.0276 mm`** |
| **Upper Control Limit ($\text{UCL}_{\bar{X}}$)** | $\bar{\bar{x}} + A_2\bar{R} = 25.0067 + 0.577(0.0276)$ | **`25.0226 mm`** |
| **Lower Control Limit ($\text{LCL}_{\bar{X}}$)** | $\bar{\bar{x}} - A_2\bar{R} = 25.0067 - 0.577(0.0276)$ | **`24.9907 mm`** |
| **$1\sigma_{\bar{X}}$ Zone Width** | $(\text{UCL}_{\bar{X}} - \text{CL}_{\bar{X}})/3$ | **`0.0053 mm`** (`+2σ = 25.0173 mm`) |
| **Upper Control Limit ($\text{UCL}_R$)** | $D_4\bar{R} = 2.114(0.0276)$ | **`0.0584 mm`** (`LCL_R = 0.0000`) |

- **สถิติชิ้นงานรายชิ้นทั้งหมด 125 ชิ้น:** ต่ำสุด `24.960 mm` — สูงสุด `25.068 mm` → **ยังไม่มีแม้แต่ชิ้นเดียวที่หลุด Spec (`24.920 – 25.080 mm`)!**

### เฉลย Step 2: ตรวจสอบ $R$ Chart ก่อน แล้วตามด้วย $\bar{X}$ Chart (WE Rules 1–4)

1. **ตรวจ $R$ Chart (ความแปรปรวนภายในกลุ่ม) ก่อนเสมอ:**
   - **`SG-11` (`18:00` Day):** `R = 0.0720 mm > UCL_R (0.0584 mm)` → **Out-of-Control (WE Rule 1 บน R Chart!)**
   - *การวินิจฉัย:* ความกว้างภายใน 5 ชิ้นที่ผลิตติดกันพุ่งเกิน `2.6 เท่า` ของ $\bar{R}$ ปกติ (มักเกิดจากจับยึดหลวม หรือคมมีดบิ่นกะทันหัน) — ส่วนอีก 24 Subgroups ที่เหลืออยู่ใน `UCL_R` ทั้งหมด
2. **ตรวจ $\bar{X}$ Chart (ตำแหน่งค่าเฉลี่ย) ด้วย WE Rules 1–4:**
   - **Rule 1 (`1 > 3σ`):** **`SG-11`** (`X̄ = 25.0350 > UCL_X 25.0226`, `+5.32σ`)
   - **Rule 4 (`8 จุดติดกันด้านเดียวกับ CL`):** **`SG-18` ถึง `SG-25`** (`01:00–08:00` จำนวน `8` Subgroups ต่อเนื่อง) ค่าเฉลี่ยอยู่ตั้งแต่ `25.0074` ถึง `25.0202 mm` ซึ่ง **อยู่เหนือ `CL = 25.0067` ทั้ง 8 จุดติดกัน!**
   - **Rule 2 (`2 ใน 3 จุดใน Zone A > +2σ`):** ในกลุ่ม `SG-23 (25.0192)`, `SG-24 (25.0202)`, และ `SG-25 (25.0180)` อยู่เกิน `+2σ (25.0173 mm)` ทั้ง 3 จุดติดกัน!
   - **จุดน่าทึ่งทางวิศวกรรม:** ช่วง `SG-18..25` **ไม่มีจุดใดทะลุเส้น `UCL_X = 25.0226` เลยแม้แต่จุดเดียว!** หากโรงงานเปิดใช้แค่ Rule 1 อย่างเดียวจะ **ตรวจไม่เจอการ Shift ครั้งนี้เลย** แต่ WE Rule 4 และ Rule 2 จับได้แม่นยำ!
   - *(หมายเหตุ: ช่วง `SG-01..10` และ `SG-12..17` ทั้ง 16 กลุ่มไม่มีจุดใดติดกฎ WE Rules 1–4 เลย)*

### เฉลย Step 3: คำนวณ Revised Control Limits (Phase I → Phase II)

- เมื่อตรวจพบสาเหตุรากเหง้าและแก้ไข `SG-11` (เปลี่ยนมีดบิ่น) และ `SG-18..25` (แก้ Offset กะดึก) แล้ว เราจึงตัด `9` Subgroups ที่มี Special Cause ออก เหลือ **`16` Subgroups ที่เสถียร (`SG-01..10, SG-12..17`)**:

| พารามิเตอร์ | Trial Limits (`25` กลุ่ม) | Revised Limits (`16` กลุ่มเสถียร) | ผลเปลี่ยนแปลง |
|---|---|---|---|
| **$\text{CL}_{\bar{X}}$** | `25.0067 mm` | **`25.0013 mm`** | กลับเข้าใกล้ Target `25.000 mm` เป๊ะ |
| **$\text{UCL}_{\bar{X}} / \text{LCL}_{\bar{X}}$** | `25.0226` / `24.9907` | **`25.0181` / `24.9845`** | เส้นแคบและตรงศูนย์ขึ้น (ไม่ถูก Shift ดึงเพี้ยน) |
| **$\text{CL}_R / \text{UCL}_R$** | `0.0276` / `0.0584` | **`0.0291` / `0.0616`** | ทั้ง 16 กลุ่มผ่านเกณฑ์เสถียร 100% (`UCL` พร้อม Freeze เข้า Phase II) |

### เฉลย Step 4: สรุปบทเรียนสำคัญที่ได้จาก Workshop นี้
1. **SPC คือระบบ Prevention:** ถึงแม้ชิ้นงานสูงสุด (`25.068 mm`) จะยังอยู่ต่ำกว่า `USL (25.080 mm)` แต่ Control Chart จับทั้ง `SG-11` และ `SG-18..25` ได้ตั้งแต่ยังไม่เกิดของเสียแม้แต่ชิ้นเดียว!
2. **ห้ามดูแค่ Rule 1 อย่างเดียว และห้ามลืม R Chart:** `SG-11` พังที่ R Chart ก่อน, ส่วน `SG-18..25` ต้องใช้ **Rule 2 + Rule 4** จึงจับเจอก่อนหลุด `UCL`!
