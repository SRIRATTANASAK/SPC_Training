## Workshop: วิเคราะห์ข้อมูล CTQ ชิ้นงานจริง (ใช้ใน `M2L4-S06` & `S07`)
- **ไฟล์ข้อมูล:** [data/workshop_m2_ctq_parts.csv](data/workshop_m2_ctq_parts.csv)
- **บริบทหน้างาน:** วัดขนาดเส้นผ่านศูนย์กลางรูเจาะ (`Bore_Diameter_mm`) จากเครื่องกลึง CNC จำนวน **50 ชิ้น** แบ่งเก็บชั่วโมงละ **1 Subgroup (`SG-01` .. `SG-10`, กลุ่มละ `n = 5` ชิ้น)**
- **Specification ลูกค้า:** `20.00 ± 0.10 mm` (`LSL = 19.90 mm`, `Target = 20.00 mm`, `USL = 20.10 mm`)

---

### เฉลย Step 1: สถิติภาพรวมทั้งหมด (`n = 50` ชิ้น)
- **Mean ($\bar{x}$):** `20.0102 mm`
- **Sample SD ($s$):** `0.0356 mm`
- **Z-Score เทียบ Spec:**
  - $Z_{\text{USL}} = \frac{20.10 - 20.0102}{0.0356} = \mathbf{+2.52}$ → พื้นที่หางบน = `0.59%`
  - $Z_{\text{LSL}} = \frac{19.90 - 20.0102}{0.0356} = \mathbf{-3.10}$ → พื้นที่หางล่าง = `0.10%`
- **คาดการณ์ของเสียรวม (Normal Prediction):** `0.59% + 0.10%` ≈ **`0.68%`** (`~6,800 PPM`)
- **ของเสียจริงในชุดข้อมูล (`> 20.10 mm`):** พบ `2` ชิ้น (`P42 = 20.11 mm`, `P44 = 20.12 mm` = `4.0%`) ทั้งคู่อยู่ใน `SG-09`!

### เฉลย Step 3: เปรียบเทียบ Baseline ที่เสถียร (`n = 45`, ตัด `SG-09`) และพิสูจน์กฎ CLT

| ตัวชี้วัด | รวมทั้งหมด (`n = 50`) | เฉพาะช่วงเสถียร (`n = 45`) | ความหมายเชิงวิศวกรรม |
|---|---|---|---|
| **Mean ($\bar{x}$)** | `20.0102 mm` | **`20.0009 mm`** | แทบตรง Target `20.00 mm` เป๊ะ! |
| **Sample SD ($s$)** | `0.0356 mm` | **`0.0220 mm`** | ความแปรปรวนลดลงเกือบ 40% |
| **$Z_{\text{USL}}$ / $Z_{\text{LSL}}$** | `+2.52 / -3.10` | **`+4.50 / -4.58`** | ห่าง Spec มากกว่า `4.5σ` ทั้ง 2 ข้าง! |
| **Predicted OOS** | `0.68%` | **`< 0.001%` (~3.4 PPM)** | กระบวนการพื้นฐานดีมาก แค่ต้องกัน Special Cause |
| **Theoretical SE ($\sigma_{\bar{x}} = s/\sqrt{5}$)** | `0.0159 mm` | **`0.0099 mm`** | กราฟ $\bar{X}$ แคบกว่าชิ้นงานจริง `√5 ≈ 2.24` เท่า! |

- **พิสูจน์ความไวของ CLT:** ด้วย Standard Error เพียง `0.0099 mm` การที่ `SG-09` พุ่งไปที่ `20.094 mm` คิดเป็นระยะห่างถึง **$(20.094 - 20.0009) / 0.0099 \approx +9.4\sigma_{\bar{x}}$** (ทะลุเส้น `3σ` ขาดลอย — Control Chart จะร้องเตือนทันที!)

### เฉลย Step 4: มุมมอง Attribute (Binomial & Poisson)
- **Binomial Defective Rate ($\hat{p}$):** มีชิ้นที่ `Visual_Pass_Fail = Fail` จำนวน `4` ชิ้น จาก `50` ชิ้น → $\hat{p} = 4/50 = \mathbf{8.0\%}$ (`0.08`) *(ทั้งหมดเกิดใน `SG-09`)*
- **Poisson Defect Rate ($\hat{\lambda}$):** ผลรวม `Surface_Defect_Count` ทั้งหมด = `9` จุด จาก `50` ชิ้น → $\hat{\lambda} = 9/50 = \mathbf{0.18\text{ defects/part}}$
