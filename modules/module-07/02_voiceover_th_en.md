## LESSON M7-L2: SPC Across 4 Core Manufacturing Processes

### AUD-M7L2-S01 (40 sec) — Machining Processes
- **Display Script (TH):**  
  มาดู 4 กระบวนการหลักครับ เริ่มที่ **งานกลึงเจียร Machining** [ANIM: machining_spc] ตัวร้ายหลักคือ **มีดกลึงสึกหรอ** ให้เก็บ 5 ชิ้นต่อเนื่องด้วย $\bar{X}$-$R$ และเปิด **Trend Rule** คอยเตือน [PAUSE-1] ถ้าคุมความหยาบผิว **Roughness** อย่าลืมตัด `LCL` ติดลบออก เหลือเฉพาะ `UCL` และทุกครั้งที่เปลี่ยนมีดต้องลง **Event Log** ทันทีครับ
- **TTS Clean Script (TH):**

- **EN Reference:**  
  In machining, tool wear drives drift—use consecutive X-bar R subgroups with trend rules, apply UCL-only bounds for surface roughness, and always log tool changes.

- **EN Reference:**  
  For automated torque or press-fit assembly, pair PLC 100% I-MR tracking with instant interlocks; for multi-site SMT boards, apply X-bar S and u charts.

### AUD-M7L2-S03 (45 sec) — Injection Molding

- **TTS Clean Script (TH):**

- **EN Reference:**

  ระวังโรค **"Wallpaper SPC"** นะครับ [PAUSE-1] [ANIM: wallpaper_spc] คือการจดตัวเลขใส่กระดาษทั้งวัน แล้วค่อยมาวาดกราฟตอนสี่โมงสี่สิบห้าก่อนเลิกงาน แบบนั้นถ้าเครื่องพังตอนเช้าก็เสียของไปแล้วทั้งวัน วัดปุ๊บ **ต้องพล็อตทันทีภายใน 1 นาที** ครับ!
- **TTS Clean Script (TH):**  
  ระวังโรค วอลเปเปอร์ เอสพีซี นะครับ, คือการจดตัวเลขใส่กระดาษทั้งวัน แล้วค่อยมาวาดกราฟตอนสี่โมงสี่สิบห้าก่อนเลิกงาน แบบนั้นถ้าเครื่องพังตอนเช้าก็เสียของไปแล้วทั้งวัน วัดปุ๊บ ต้องพล็อตทันทีภายใน 1 นาที ครับ
- **EN Reference:**

### AUD-M7L3-S02 (40 sec) — Actionable Reaction Plan
- **Display Script (TH):**  
  Reaction Plan ใน Control Plan ที่เขียนสั้นๆ ว่า *"แจ้งหัวหน้างาน"* ใช้ไม่ได้จริงครับ! [ANIM: reaction_morph] ต้องเขียนเป็นคำสั่งปฏิบัติที่ระบุชัดว่า **หยุดจุดไหน วัดซ้ำกี่นาที กักกันย้อนหลังถึงจุดที่ดีล่าสุดเท่าไร และตรวจเช็กชิ้นส่วนใดของเครื่องจักร** ครับ
- **TTS Clean Script (TH):**  
  รีแอคชั่น แพลน ใน คอนโทรล แพลน ที่เขียนสั้นๆ ว่า แจ้งหัวหน้างาน ใช้ไม่ได้จริงครับ ต้องเขียนเป็นคำสั่งปฏิบัติที่ระบุชัดว่า หยุดจุดไหน วัดซ้ำกี่นาที กักกันย้อนหลังถึงจุดที่ดีล่าสุดเท่าไร และตรวจเช็กชิ้นส่วนใดของเครื่องจักร ครับ
- **EN Reference:**  
  Replace vague reaction instructions like 'notify supervisor' with specific, time-bound steps: pause, re-verify, quarantine back to the last good subgroup, and inspect target tooling.

### AUD-M7L3-S03 (45 sec) — 3-Tier Escalation Matrix & SLA
- **Display Script (TH):**

- **TTS Clean Script (TH):**
