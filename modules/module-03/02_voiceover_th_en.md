## LESSON M3-L3: Hypothesis Testing

### AUD-M3L3-S01 (35 sec) — Null vs Alternative Hypothesis
- **Display Script (TH):**  
  การทดสอบสมมติฐานเปรียบเหมือนการพิจารณาคดีในศาล [PAUSE-1] [ANIM: courtroom_scale] **$H_0$ หรือ Null Hypothesis** คือสมมติฐานตั้งต้นว่า "ไม่มีความต่าง" เช่น เครื่อง A กับ B เท่ากัน ส่วน **$H_1$** คือสิ่งที่เราสงสัยว่าต่าง [PAUSE-1] เราจะยึด $H_0$ ไว้ก่อนจนกว่าหลักฐานตัวเลขจะแน่นพอจึงจะปฏิเสธ $H_0$ ได้
- **TTS Clean Script (TH):**  
  การทดสอบสมมติฐานเปรียบเหมือนการพิจารณาคดีในศาล, เอชศูนย์ หรือ นัล ฮัยพอธีซิส คือสมมติฐานตั้งต้นว่า ไม่มีความต่าง เช่น เครื่อง เอ กับ บี เท่ากัน, ส่วน เอชหนึ่ง คือสิ่งที่เราสงสัยว่าต่าง, เราจะยึด เอชศูนย์ ไว้ก่อนจนกว่าหลักฐานตัวเลขจะแน่นพอจึงจะปฏิเสธ เอชศูนย์ ได้
- **EN Reference:**  
  Hypothesis testing works like a courtroom trial: the null hypothesis assumes no difference until sample evidence strongly contradicts it in favor of the alternative.

### AUD-M3L3-S02 (35 sec) — Alpha Risk
- **Display Script (TH):**  
  ในการตัดสินใจย่อมมีความเสี่ยง 2 ด้าน [ANIM: alpha_tails] ด้านแรกคือ **Alpha Risk หรือ Type I Error** คือการ **เตือนผิดพลาด (False Alarm)** — ปฏิเสธ $H_0$ ทั้งที่ความจริงเครื่องจักรไม่ต่างกันเลย เช่น สั่งหยุดไลน์ปรับเครื่องฟรีๆ ปกติเรากำหนดเพดานความเสี่ยงนี้ไว้ที่ **0.05 หรือ 5%**
- **TTS Clean Script (TH):**  
  ในการตัดสินใจย่อมมีความเสี่ยง 2 ด้าน, ด้านแรกคือ อัลฟ่า ริสก์ หรือ ไทป์ วัน เออร์เรอร์ คือการเตือนผิดพลาด หรือ ฟอลส์ อลาร์ม, ปฏิเสธ เอชศูนย์ ทั้งที่ความจริงเครื่องจักรไม่ต่างกันเลย เช่น สั่งหยุดไลน์ปรับเครื่องฟรีๆ ปกติเรากำหนดเพดานความเสี่ยงนี้ไว้ที่ 0.05 หรือ 5 เปอร์เซ็นต์
- **EN Reference:**  
  Alpha risk, or Type I error, is a false alarm—rejecting the null hypothesis when no real difference exists, typically capped at 5%.

### AUD-M3L3-S03 (40 sec) — Beta Risk & Power
- **Display Script (TH):**  
  ความเสี่ยงด้านที่สองคือ **Beta Risk หรือ Type II Error** [PAUSE-1] [ANIM: beta_power] คือ **พลาดจับความผิดปกติไม่เจอ (Escape)** ทั้งที่เครื่องจักรเพี้ยนไปแล้ว! ส่วน **1 ลบ Beta เรียกว่า Statistical Power** คือพลังในการจับความต่างที่เกิดขึ้นจริง ซึ่งในโรงงานควรตั้งเป้า Power อย่างน้อย **80%** ด้วยการเก็บ Sample Size ให้พอ
- **TTS Clean Script (TH):**  
  ความเสี่ยงด้านที่สองคือ เบต้า ริสก์ หรือ ไทป์ ทู เออร์เรอร์, คือพลาดจับความผิดปกติไม่เจอ หรือ เอสเคป ทั้งที่เครื่องจักรเพี้ยนไปแล้ว, ส่วน 1 ลบ เบต้า เรียกว่า สแตทิสติคอล พาวเวอร์ คือพลังในการจับความต่างที่เกิดขึ้นจริง ซึ่งในโรงงานควรตั้งเป้า พาวเวอร์ อย่างน้อย 80 เปอร์เซ็นต์ ด้วยการเก็บขนาดตัวอย่างให้พอ
- **EN Reference:**  
  Beta risk, or Type II error, is missing a real difference. One minus beta is statistical power—the probability of detecting a true shift, targeted at 80% or higher.

### AUD-M3L3-S04 (35 sec) — Understanding p-value
- **Display Script (TH):**  
  ตัวตัดสินในโปรแกรมสถิติทุกตัวคือ **p-value** [PAUSE-1] [ANIM: pval_gauge] ท่องกฎง่ายๆ เลย: **"If the p is low, the Null must go!"** ถ้า **p-value น้อยกว่า 0.05** เราปฏิเสธ $H_0$ สรุปว่าต่างจริง แต่ถ้า **p-value มากกว่าหรือเท่ากับ 0.05** แปลว่าหลักฐานยังไม่พอสรุปว่าต่าง
- **TTS Clean Script (TH):**  
  ตัวตัดสินในโปรแกรมสถิติทุกตัวคือ พีแวลู, ท่องกฎง่ายๆ เลย ถ้าค่า พี ต่ำ เอชศูนย์ ต้องไป, ถ้า พีแวลู น้อยกว่า 0.05 เราปฏิเสธ เอชศูนย์ สรุปว่าต่างจริง แต่ถ้า พีแวลู มากกว่าหรือเท่ากับ 0.05 แปลว่าหลักฐานยังไม่พอสรุปว่าต่าง
- **EN Reference:**  
  Remember the rule: if the p is low, the null must go. A p-value below 0.05 rejects the null hypothesis; 0.05 or above means insufficient evidence to reject it.

### AUD-M3L3-S05 (35 sec) — Statistical vs Practical Significance
- **Display Script (TH):**  
  ข้อควรจำสำคัญของวิศวกรระดับ Senior [PAUSE-1] [ANIM: stat_vs_prac] ถ้าเราเก็บตัวอย่างเยอะมากเป็นหมื่นชิ้น ความต่างแค่ 0.002 มิลลิเมตร ก็อาจได้ p-value ต่ำกว่า 0.05 ได้ [PAUSE-1] ดังนั้น **ต้องเอา Confidence Interval ของความต่างมาเทียบกับ Spec เสมอ** ว่าความต่างนั้นคุ้มค่าที่จะลงมือแก้ไขในทางวิศวกรรมหรือไม่
- **TTS Clean Script (TH):**  
  ข้อควรจำสำคัญของวิศวกรระดับ ซีเนียร์, ถ้าเราเก็บตัวอย่างเยอะมากเป็นหมื่นชิ้น ความต่างแค่ 0.002 มิลลิเมตร ก็อาจได้ พีแวลู ต่ำกว่า 0.05 ได้, ดังนั้น ต้องเอาช่วงความเชื่อมั่นของความต่างมาเทียบกับ สเปก เสมอ ว่าความต่างนั้นคุ้มค่าที่จะลงมือแก้ไขในทางวิศวกรรมหรือไม่
- **EN Reference:**  
  With huge sample sizes, tiny differences can yield p below 0.05. Always compare the confidence interval of the difference against engineering tolerances for practical significance.

### AUD-M3L4-S01 (35 sec) — Test Roadmap & Assumptions

- **TTS Clean Script (TH):**

- **EN Reference:**

### AUD-M3L4-S02 (40 sec) — 1-Sample T-Test
- **Display Script (TH):**  
  **1-Sample T-Test** ใช้เทียบค่าเฉลี่ยของ 1 เครื่องจักรกับค่าเป้าหมาย [PAUSE-1] [ANIM: one_sample] ตัวอย่างเช่น เครื่อง A สุ่ม 20 ชิ้นได้แรงดึงเฉลี่ย 119.5 นิวตัน เทียบกับเป้า 120.0 นิวตัน คำนวณค่า t ได้ -1.415 และ p-value เท่ากับ 0.173 ซึ่งมากกว่า 0.05 จึงสรุปได้ว่าเครื่อง A ยังไม่ต่างจากเป้าอย่างมีนัยสำคัญ
- **TTS Clean Script (TH):**  
  วัน แซมเปิล ทีเทสต์ ใช้เทียบค่าเฉลี่ยของ 1 เครื่องจักรกับค่าเป้าหมาย, ตัวอย่างเช่น เครื่อง เอ สุ่ม 20 ชิ้นได้แรงดึงเฉลี่ย 119.5 นิวตัน เทียบกับเป้า 120.0 นิวตัน คำนวณค่า ที ได้ ลบ 1.415 และ พีแวลู เท่ากับ 0.173 ซึ่งมากกว่า 0.05 จึงสรุปได้ว่าเครื่อง เอ ยังไม่ต่างจากเป้าอย่างมีนัยสำคัญ
- **EN Reference:**  
  A 1-sample t-test compares a single process mean against a target. For Machine A, p equals 0.173, so we do not reject the 120 N target.

### AUD-M3L4-S03 (45 sec) — 2-Sample vs Paired T-Test
- **Display Script (TH):**  
  **2-Sample T-Test** ใช้เทียบ 2 กลุ่มที่เป็นอิสระต่อกัน เช่น เทียบชิ้นงาน 20 ชิ้นจากเครื่อง A กับอีก 20 ชิ้นจากเครื่อง B [PAUSE-1] [ANIM: two_vs_paired] แต่ถ้าคุณเอา **ชิ้นงานชุดเดียวกัน** ไปวัดก่อนและหลังอบความร้อน หรือเทียบเครื่องมือวัด 2 ตัวบนชิ้นเดิม แบบนี้ต้องใช้ **Paired T-Test** เพื่อลดความแปรปรวนระหว่างชิ้นงาน
- **TTS Clean Script (TH):**  
  ทู แซมเปิล ทีเทสต์ ใช้เทียบ 2 กลุ่มที่เป็นอิสระต่อกัน เช่น เทียบชิ้นงาน 20 ชิ้นจากเครื่อง เอ กับอีก 20 ชิ้นจากเครื่อง บี, แต่ถ้าคุณเอาชิ้นงานชุดเดียวกันไปวัดก่อนและหลังอบความร้อน หรือเทียบเครื่องมือวัด 2 ตัวบนชิ้นเดิม แบบนี้ต้องใช้ แพร์ด ทีเทสต์ เพื่อลดความแปรปรวนระหว่างชิ้นงาน
- **EN Reference:**  
  Use a 2-sample t-test for independent groups like Machine A versus Machine B, and a paired t-test when measuring the exact same parts twice such as before-and-after testing.

### AUD-M3L4-S04 (45 sec) — ANOVA Concept Introduction
- **Display Script (TH):**  
  แล้วถ้าต้องเทียบ 4 แม่พิมพ์ หรือ 3 เครื่องจักรพร้อมกัน? [PAUSE-1] [ANIM: anova_f] อย่าเอา 2-Sample T-Test มาเทียบทีละคู่ เพราะความเสี่ยง False Alarm รวมจะพุ่งจาก 5% เป็น 26.5% ทันที! [PAUSE-1] เราต้องใช้ **ANOVA** ที่เปรียบเทียบความแปรปรวน *ระหว่างกลุ่ม* หารด้วย *ภายในกลุ่ม* ออกมาเป็นค่า F ถ้า p-value ต่ำกว่า 0.05 จึงตามไปดูว่าตัวไหนต่าง
- **TTS Clean Script (TH):**  
  แล้วถ้าต้องเทียบ 4 แม่พิมพ์ หรือ 3 เครื่องจักรพร้อมกัน, อย่าเอา ทู แซมเปิล ทีเทสต์ มาเทียบทีละคู่ เพราะความเสี่ยง ฟอลส์ อลาร์ม รวมจะพุ่งจาก 5 เปอร์เซ็นต์ เป็น 26.5 เปอร์เซ็นต์ ทันที, เราต้องใช้ อะโนว่า ที่เปรียบเทียบความแปรปรวนระหว่างกลุ่มหารด้วยภายในกลุ่มออกมาเป็นค่า เอฟ ถ้า พีแวลู ต่ำกว่า 0.05 จึงตามไปดูว่าตัวไหนต่าง
- **EN Reference:**  
  When comparing three or more groups, avoid multiple t-tests which inflate alpha error. One-way ANOVA tests all means simultaneously using the F-ratio of between-group to within-group variance.
