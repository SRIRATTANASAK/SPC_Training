# Module 3 Screen Wireframe (Web-First & Responsive Ready)

## Global Layout Standard
- Header (10%): Breadcrumb (`Module 3 > Lesson > Screen`), Progress (`X / 26`), Language Toggle (`TH / EN`)
- Stage (75%): Interactive Canvas / Formula / Test Comparison Output
- Audio & Caption Bar (5%): Play/Pause `AUD-M3*`, Speed (`1.0x / 1.25x`), Captions
- Footer (10%): `Back` | Screen Indicator | `Resources (M3 Cheat Sheet)` | `Next`
