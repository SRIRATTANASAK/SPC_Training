## Workshop 1: จำแนกข้อมูลจริงในโรงงาน (ใช้ใน `M1L2-S04`)
- **ไฟล์ข้อมูล:** [data/workshop_m1_data_classification.csv](data/workshop_m1_data_classification.csv) (20 รายการ `DC-01` ถึง `DC-20`)
- **โจทย์สำหรับผู้เรียน:**
  1. จำแนกว่าแต่ละรายการเป็น **Variable Data** หรือ **Attribute Data**
  2. จำแนกว่าเป็น **Continuous** หรือ **Discrete**
  3. ระบุระดับ **Measurement Scale** (`Nominal`, `Ordinal`, `Interval`, `Ratio`)

### จุดหลอกที่วิศวกรต้องระวัง (Key Learning Traps)
| Item ID | ข้อมูลหน้างาน | คำตอบที่ถูกต้อง | ทำไมคนมักตอบผิด? |
|---|---|---|---|
| `DC-05` | จำนวนครีบ (Burr) ต่อชิ้น (`0, 1, 2, 3`) | **Attribute / Discrete / Ratio** | เป็น Discrete count แต่มีศูนย์แท้ (0 = ไม่มี Burr) จึงเป็น Ratio |
| `DC-06` | อุณหภูมิเตาอบ (`180.5 °C`) | **Variable / Continuous / Interval** | 0 °C ไม่ใช่จุดที่ไม่มีความร้อน จึงเป็น Interval ไม่ใช่ Ratio |
| `DC-11` | หมายเลขแม่พิมพ์ (`Cavity 1, 2, 3, 4`) | **Attribute / Discrete / Nominal** | แม้เขียนเป็นตัวเลข 1–4 แต่เป็นแค่ป้ายชื่อ ห้ามนำมาหาค่าเฉลี่ย! |
| `DC-13` | คะแนนความพึงพอใจ (`1–5 ดาว`) | **Attribute / Discrete / Ordinal** | ตัวเลขบอกลำดับ แต่ระยะห่างระหว่าง 1→2 กับ 4→5 ไม่เท่ากัน |
| `DC-18` | ผลเช็ค Go / No-Go Plug Gauge | **Attribute / Discrete / Nominal** | แม้จะเช็คขนาดรู (Dimension) แต่ค่าที่บันทึกเป็นแค่ Go/No-Go |

*(เฉลยครบทั้ง 20 ข้ออยู่ในคอลัมน์ `Category_Variable_or_Attribute`, `Data_Type_Continuous_or_Discrete`, `Measurement_Scale`, และ `Rationale` ของไฟล์ CSV)*

## Workshop 2: วิเคราะห์ข้อมูล Defect และ Dimension จริง (ใช้ใน `M1L3` & `M1L4-S07`)
- **ไฟล์ข้อมูล:** [data/workshop_m1_dimensions_and_defects.csv](data/workshop_m1_dimensions_and_defects.csv) (30 ชิ้นงาน `Sample 1–30` จากเครื่อง `MC-A` และ `MC-B`)
- **เป้าหมายวิศวกรรม:** Spec ขนาดเพลา = `50.00 ± 0.05 mm` (`LSL = 49.95 mm`, `USL = 50.05 mm`)

### Part A: เฉลย Descriptive Statistics (ตรวจสอบแล้วจากข้อมูล CSV)

| ตัวชี้วัด | ภาพรวมทั้งหมด (`n = 30`) | เครื่อง `MC-A` (`n = 15`) | เครื่อง `MC-B` (`n = 15`) |
|---|---|---|---|
| **Mean ($\bar{x}$)** | `50.0293 mm` | `50.0080 mm` | `50.0507 mm` |
| **Median** | `50.0250 mm` | `50.0100 mm` | `50.0400 mm` |
| **Mode** | `50.00 mm` | `50.00 mm` | `50.03 & 50.04 mm` |
| **Min / Max** | `49.98 / 50.14 mm` | `49.98 / 50.04 mm` | `50.02 / 50.14 mm` |
| **Range ($R$)** | `0.1600 mm` | `0.0600 mm` | `0.1200 mm` |
| **Sample Variance ($s^2$)** | `0.001027 mm²` | `0.000231 mm²` | `0.000921 mm²` |
| **Sample SD ($s$)** | `0.0320 mm` | `0.0152 mm` | `0.0303 mm` |
| **CV (%)** | `0.0641 %` | `0.0304 %` | `0.0606 %` |
| **Q1 / Median / Q3** | `50.0075 / 50.0250 / 50.0425` | `50.00 / 50.01 / 50.02` | `50.03 / 50.04 / 50.06` |

**ข้อค้นพบเชิงสถิติ:**
1. เครื่อง `MC-B` มีค่าเฉลี่ยเบี่ยงสูงกว่าเป้าหมาย (`50.0507 mm` ซึ่งชิดขอบ `USL = 50.05 mm`!) และมี SD สูงกว่า `MC-A` ถึง **2 เท่า** (`0.0303` vs `0.0152 mm`)
2. ชิ้นที่ 30 (`50.14 mm`) เป็น **Outlier** ชัดเจน (`> Q3 + 1.5×IQR` ของ MC-B = `50.06 + 0.045 = 50.105 mm`) ทำให้ Mean ของ MC-B ถูกดึงสูงกว่า Median (`50.0507` vs `50.0400`)

### Part B: เฉลย Data Visualization 5 กราฟหลัก

1. **Histogram (`Shaft_Diameter_mm`):**
   - เห็นรูปทรงเบ้ขวา (Right-skewed) มีหางยาวไปทาง `50.08–50.14 mm` ซึ่งเกิน `USL = 50.05 mm`
2. **Box Plot (`MC-A` vs `MC-B`):**
   - กล่องของ `MC-A` แคบและอยู่กลาง Target (`IQR = 0.02 mm`) ไม่มีจุดหลุด
   - กล่องของ `MC-B` เลื่อนขึ้นสูงกว่าชัดเจน (`Median = 50.04 mm`), กว้างกว่า (`IQR = 0.03 mm`), และแสดงจุด **Outlier ที่ `50.14 mm`**
3. **Pareto Chart (`Defect_Type` ถ่วงน้ำหนักด้วย `Defect_Count`, รวม `15 defects`):**
   - **Scratch:** `9` ครั้ง (`60.0%`, สะสม `60.0%`)
   - **Burr:** `4` ครั้ง (`26.7%`, สะสม `86.7%`)
   - **Dent:** `1` ครั้ง (`6.7%`, สะสม `93.3%`)
   - **Crack:** `1` ครั้ง (`6.7%`, สะสม `100.0%`)
   - **สรุป 80/20:** แก้แค่ **Scratch + Burr** เพียง 2 หัวข้อ จะลดของเสียได้ถึง **86.7%**!
4. **Scatter Plot (`Mold_Temp_C` vs `Shaft_Diameter_mm`):**
   - พบความสัมพันธ์เชิงบวกแข็งแรงมาก (**Pearson $r = +0.9949$**) — ยิ่งอุณหภูมิแม่พิมพ์/เครื่องจักรสูงขึ้นจาก `179 °C` เป็น `192 °C` ขนาดเพลาก็ยิ่งขยายใหญ่ขึ้นตาม
5. **Run Chart (`Sample_No 1..30` ตาม `Timestamp`):**
   - ช่วงเช้า (`08:00–11:30`, `MC-A`) ขนาดแกว่งนิ่งรอบ `50.00 mm`
   - ช่วงบ่าย (`13:00–16:30`, `MC-B`) ขนาดมีแนวโน้มไหลสูงขึ้น (**Upward Drift**) ต่อเนื่องจนทะลุ Spec ที่ `16:30`

**สรุปแผนแก้ไขเบื้องต้นสำหรับหน้างาน:** หยุดตรวจสอบระบบระบายความร้อน/อุณหภูมิของเครื่อง `MC-B` (ซึ่งเป็นต้นเหตุของ Thermal Expansion Drift) และตรวจสอบคมตัด/การจับยึดที่ก่อให้เกิด **Scratch & Burr** ครับ
